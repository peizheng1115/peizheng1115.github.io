## 🧠 Schnellübersicht: Die wichtigsten A2-Merkregeln
| Wortart | Wichtigste A2-Grammatikregel & Merkhilfe |
| :--- | :--- |
| **Verben** | **Satzklammer**: Im Hauptsatz steht das finite Verb an **Position 2**, trennbare Vorsilben oder Partizip II am **Satzende**. Perfekt mit `sein` bei Orts-/Zustandswechsel (*ist gefahren, ist aufgestanden*). |
| **Maskuline Nomen (`der`)** | Typische Endungen: `-er` (Personen), `-or`, `-ismus`, `-ling`, `-ist`. Wochentage, Monate, Jahreszeiten, Himmelsrichtungen sind fast immer maskulin. |
| **Feminine Nomen (`die`)** | Typische Endungen: `-ung`, `-heit`, `-keit`, `-schaft`, `-tion`, `-tät`, `-ei`, `-ie`, `-in` (weibliche Berufe). Fast immer `die`! |
| **Neutrale Nomen (`das`)** | Typische Endungen: `-chen`, `-lein` (Diminutive), `-ment`, `-um`, `-nis`, substantivierte Infinitive (*das Essen, das Leben*). |
| **Dativ-Präpositionen** | **Merkreim**: *Aus, bei, mit, nach, seit, von, zu, gegenüber, ab* — fordern **immer den Dativ**! |
| **Akkusativ-Präpositionen** | **Merkwort DOGFUB**: *Durch, Ohne, Gegen, Für, Um, Bis* — fordern **immer den Akkusativ**! |
| **Wechselpräpositionen** | *an, auf, hinter, in, neben, über, unter, vor, zwischen*: **Wohin?** (Richtung/Aktion) = **Akkusativ**; **Wo?** (Ort/Zustand) = **Dativ**. |
| **Konjunktionen** | **Position 0 (ADUSO)**: *aber, denn, und, sondern, oder* (keine Inversion!). **Nebensatz**: *weil, dass, wenn, ob, obwohl, damit, als* schicken das finite Verb ganz ans **Satzende**! |

> - **Wechselpräpositionen (Wohin = Akk / Wo = Dat)**: `an, auf, hinter, in, neben, über, unter, vor, zwischen`
